🤖 Development Context: Drive Shallow Mover

This document is the Absolute Source of Truth. All agents MUST strictly follow these specifications to maintain stability and prevent regressions.

1. System Architecture (Modular Hub)

ARCH Component Separation

  • Router.gs: Entry point (doGet). Responsible for page routing via ?p=... and injecting appUrl into templates.
  • Index.html: Main UI structure & logic hub. CSS is strictly forbidden (use Stylesheet.html). Holds Global State.
  • Stylesheet.html: All CSS rules. Disconnected in Gemini Preview to keep files lightweight.
  • JavaScript.html: Production JavaScript. Communicates with backend and manages parallel worker pools.
  • Code.gs: Backend Drive API (v3) functions. Sequential, stateless, and performance-optimized.

2. Global State & Scoping Rules

CRITICAL Variable Scoping

Because logic is split between Index.html and JavaScript.html, all shared data MUST be explicitly bound to the window object in Index.html to ensure cross-file visibility.

// CORRECT: Declarations in Index.html
window.currentFolderIds = []; 
window.fileNamesMap = {};

// INCORRECT: Avoid 'let' at top-level if accessed by other .html files
let folderResults = [];

3. Concurrency & Performance Strategy

PERF Parallel Batching (The 5x5 Pattern)

To bypass GAS execution limits and maximize throughput:

  • Move Operation: 5 simultaneous workers. Batch size: 5 IDs per server request.
  • Startup Jitter: Each worker MUST wait 0ms to 3000ms (Random) before its first request to prevent initial server saturation.
  • Analyze Operation: 3 simultaneous workers. Updates stats-{id} cells individually to keep UI responsive.
  • Locking: LockService is avoided in moveFiles to allow true concurrency, as the client guarantees batch isolation.

4. Robustness & Error Mitigation

CRITICAL Undefined Error Sanitization

GAS google.script.run can fail without an error object (network blip). runWithRetry MUST:

  • Check if err or err.message is null/undefined.
  • Provide a fallback message: "Unknown Network or Server Error".
  • Apply Jittered Retries (1500ms + random 1000ms) for SERVER_BUSY or Quota errors.

6. UI Implementation & Help Strategy

UI Hybrid Help System

  • In-App Modal (❓, 🛠️): Uses an iframe pointing to ?p=README or ?p=AGENTS. Preferred for context preservation.
  • Separate Window (Footer): Uses window.open(url, 'DriveShallowMoverHelp'). Named target ensures tab reuse.
  • Auto-Close: Main window attempts helpWindowRef.close() on beforeunload.

UI State Rules

  • Reset-First: Before enabling a new input mode (Date range vs Year), disable and hide ALL other related groups.
  • Permanent UI: The folder creation bar in the picker dialog is always visible. No toggle required.
  • Dynamic Init: Dropdowns (like Year list) MUST be generated in initApp to stay current (e.g., up to current year).
  • Visual Depth: Apply disabled attribute AND .input-disabled class for clarity.
