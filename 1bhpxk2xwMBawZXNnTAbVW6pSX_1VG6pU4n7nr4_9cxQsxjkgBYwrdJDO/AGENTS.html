1. System Architecture (Hybrid & Modular)

ARCH Routing & Components

  • Router.gs: Handles doGet(e). Routes to HTML files based on ?p=... parameter (e.g., ?p=Index).
  • Index.html: Logic Hub. NO CSS ALLOWED. Uses include('Stylesheet'). Contains UI Mocks.
  • Stylesheet.html: All CSS rules. Disconnected in Preview.
  • JavaScript.html: Production JS overriding mocks.
  • Code.gs: Backend Drive API logic (v3 preferred).

2. Drive API v3 Constraints

CRITICAL Update Signature

Moving files: Drive.Files.update({}, id, null, {addParents, removeParents}). 3rd arg MUST be null.

API Forbidden q-Fields

  • size: ❌ Forbidden in search query. Filter post-fetch.
  • description: ❌ Forbidden. Use fullText contains.

4. UI Logic & Feedback Rules

UI Modal & Interaction

  • Reset-First Rule: Toggling conditional groups: Disable/hide all groups first, then enable the target. Set disabled = true/false directly.
  • Checkbox Values: Dynamic rows MUST set value="${file.id}".
  • Smart Picker: If ID exists, openPicker calls getParentId(value).
  • NEW Inline Creation: The folder picker supports inline folder creation. After creation, the CacheService key for the parent folder MUST be removed, and the list refreshed using bypassCache = true.
  • Elapsed Time Display: The action button must display elapsed time (e.g., (15s elapsed)) during long processes.

5. Concurrency & Performance

PERF Batch Processing

  • Iterate in JavaScript on the client side.
  • IDs are grouped into batches of 10 per server request to prevent timeout.
