Drive Shallow Mover ユーザーガイド

Drive Shallow Mover は、Google ドライブ内のファイルを「再帰的ではなく（Shallow）」、「条件を指定して」、「一括で」整理するためのツールです。

指定したフォルダの直下にあるファイルだけを操作対象とするため、意図せずサブフォルダの中身まで移動してしまう事故を防ぎながら、大量のファイルを効率的に整理できます。

🚀 主な機能と特徴

  • 安全な浅層移動: フォルダ階層を深く潜ることなく、指定場所の表面にあるファイルのみを扱います。
  • 高度な検索フィルター: ファイル名（除外条件含む）、更新日時（年単位・相対指定）、ファイル形式などで絞り込み可能です。
  • 高速な並列処理: ファイル移動などの重い処理は、並列バッチ処理により高速に実行されます。
  • 状態の自動保存: 入力した検索条件や移動先は自動的に保存され、次回起動時に復元されます。

1. 検索条件の設定

移動させたいファイルを特定するための条件を入力します。

基本条件

  • 場所: 「マイドライブ直下」または「特定のフォルダ内」を選択できます。
  • ファイル名: 特定の文字を含むファイルを検索します。
  • 除外キーワード New: ファイル名に特定の文字が含まれるものを除外します（最大5つまで指定可能）。「コピー」「古い版」などを除外するのに便利です。

高度な絞り込み

  • ファイル形式:
    • 「フォルダ以外」: 整理の際にフォルダを残してファイルだけ動かしたい場合に最適です。
    • 「マークダウン (.md)」: 拡張子だけでなく、Googleドライブ上のMIMEタイプも考慮して漏れなく検索します。
  • 最終更新日時:
    • 日付範囲: カレンダーで期間を指定。
    • 相対指定: 「現在から 7日 以前」のような指定。
    • 年単位 New: 「2024年」などを選ぶだけで、その年の1月1日〜12月31日を自動設定します。
  • 本文・説明文: ファイルの中身や、プロパティの「説明」欄を検索します。

2. フォルダの選択・作成

検索場所や移動先を指定するための「選択」ボタンを押すと、専用ダイアログが開きます。

  • 階層移動: フォルダ名をダブルクリックで中に入り、上部のパンくずリストや「⬆️ 親へ」ボタンで戻ります。
  • スマートオープン: すでにIDが入力されている場合、そのフォルダが見える階層（親フォルダ）を自動で開きます。
  • 新規フォルダ作成 New: ダイアログ上部の入力欄から、その場ですぐに新しいフォルダを作成できます。作成後は即座にリストに反映されます。

3. 検索結果の確認と選択

「検索を実行」すると、結果が「フォルダ」タブと「ファイル」タブに分かれて表示されます。

  • 内訳を集計 New: フォルダタブにあるこのボタンを押すと、各フォルダの中に「ファイルがいくつあるか」を集計して表示します。中身が空のフォルダを探す際などに役立ちます。
  • 件数指定読み込み New: 検索結果が多い場合、リスト下部から「100件」「500件」など件数を指定して続きを読み込めます。
  • 一括選択: 表のヘッダーにあるチェックボックスで、表示されている全アイテムを選択／解除できます。

4. 移動の実行

移動先フォルダIDを指定し、「選択したアイテムを移動する」ボタンを押すと処理が始まります。

  • 進捗表示: ボタン上に「経過時間（秒）」が表示され、プログレスバーで全体の進捗が可視化されます。
  • 並列バッチ処理: 効率化のため、複数のファイルをまとめて並列に処理します。
  • エラーレポート: 権限不足などで移動できなかったファイルがある場合、処理完了後に詳細なエラーリストが表示されます。
⚠️ 制限事項
  • ファイルサイズ検索: APIの仕様上、検索クエリでのサイズ絞り込みはできません。リスト取得後の目視確認が必要です。
  • 最大表示件数: ブラウザのパフォーマンスを維持するため、大量のファイルがある場合は「追加読み込み」を使って順次表示してください。
